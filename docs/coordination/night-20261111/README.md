# Closed-record compatibility paths

The [canonical night archive](<../dsh/archive/night-20261111/README.md>) preserves the closed campaign record.
Exactly five original regular-file copies remain here for the installed Explorer's fixed, no-symlink reader: [CONTROL.json](<CONTROL.json>), [RUN-UPDATES.md](<RUN-UPDATES.md>), [SPR-01.md](<SPR-01.md>), [SPR-01-B.md](<SPR-01-B.md>) and [H3.md](<H3.md>).
They are byte-identical closed records, not a second set of live boards. Old active flags, dates and permissions do not resume a scope.
The [migration manifest](<../migration-manifest.json>) maps every copy; current DSH instructions live in the [DSH index](<../dsh/README.md>).
