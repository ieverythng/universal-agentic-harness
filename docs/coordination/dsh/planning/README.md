# Planning and assessment navigation

Useful plans are retained for review and reuse, not discarded merely because
their execution windows ended. This index separates **reusable planning**, dated
execution/review receipts and actual publication. It creates no sprint brief,
implementation dispatch, resumed deadline or H-gate acceptance. The human is
still reviewing the sprint work; no execution is authorized by this catalog.

  writer suite. Local acceptance/staging is not a commit, push, PR, merge or tag.
- **Publication** and **H qualification** need their own evidence and owner.
  Source test counts below are recorded historical receipts, not tests rerun here.

## Custody and the next decision

Historical absolute paths in source boards identify their **old writer/operator
contexts**, not the present documentation worktree or portable installation
instructions. Unique external source units, planning seeds, receipts and worktrees
remain in place. A link's existence is not a new hash/index/review qualification;
missing local access is not authority to delete, relocate or reconstruct it.

Current Git hold remains: the human owns commits/pushes. Any later publication or
main-then-isolated-base integration is a separate reviewed decision; do not overlay
a dirty root, stage raw seeds or revive an expired campaign. GRILL collects the
human's chosen next assessment/scope and preserves exact predecessor manifests.
