### Minimal next correction scope, not authorized implementation

1. Enforce exclusive workspace ownership across every supported public owner
   instance. For a single-process fixture, either reject a second live owner
   before mutation or give owners of the same canonical workspace one
   domain-local ownership/fence primitive. Existing instance RLocks do not
   provide this property. Supporting separate processes would require an
   explicit domain-local process exclusion contract; it is not claimed here.
   Do not introduce a global lock framework or another lifecycle store.
2. Validate retained compiled-task and nested task bodies with their owning
   artifact identity contract, including reconstruction before observation
   replay. ExactNoteOracle.issue and require_task already check concrete tasks;
   the retained-body path must meet the same content association. A newly hashed
   outer oracle cannot validate stale inner content. No generic validator or
   duplicate compiler identity algorithm is selected by this handoff.
3. Prevent native note writes from modifying externally aliased inodes. A
   domain-local fresh-file replacement or explicit alias rejection needs public
   tests for unchanged outside content. Parent-directory ownership and path
   assumptions must be explicit; a symlink check alone is insufficient.
