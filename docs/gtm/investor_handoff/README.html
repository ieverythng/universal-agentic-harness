Package purpose

This package explains the Universal Agentic Harness (UAH) and NeuralWorkbench as one product thesis with separate authority boundaries:

  • UAH is the portable control kernel. It compiles task scope, constrains model proposals, preserves domain ownership, and records evidence.
  • NeuralWorkbench is the H3+ adaptive engine. It retrieves prior experience, constructs and compares candidate interaction structures, and proposes reusable structures without receiving execution authority.
  • Observatory is the read-only evidence surface. It renders model output, admission, execution, evidence, acceptance, and Workbench provenance without becoming another source of truth.

The package separates implemented behavior from the roadmap. Commercial and market statements are hypotheses for validation unless identified as repository evidence.
